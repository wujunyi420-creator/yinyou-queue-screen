      排队大屏 · 使用指南 (Linux / macOS)
═══════════════════════════════════════════

【这是什么】
局域网排队叫号系统，支持：
- 控制台改 LOGO/店名/价格、管理排队、叫号
- 大屏展示排队、语音播报叫号
- 顾客手机扫码自助取号（C 前缀号码）
- 等待时长预估（基于历史叫号数据）

架构：控制台机器跑服务，大屏/手机用浏览器访问。


───────────────────────────────────────────
一、首次使用（只需做一次）
───────────────────────────────────────────

1. 解压到一个文件夹，应有以下内容：
   · start.sh           启动脚本
   · server.js          服务程序
   · console.html       控制台页面
   · display.html       大屏页面
   · take.html          取号页（顾客手机用）
   · forum.html         社区论坛
   · bg.png             背景图
   · state.json         数据文件
   · audio/             语音文件目录
   · uploads/           上传文件目录
   · 使用指南.txt

2. 安装 Node.js（仅控制台机器需要）
   · macOS (推荐 Homebrew):
       brew install node
     如未安装 Homebrew:
       /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
   · Ubuntu/Debian:
       sudo apt update && sudo apt install -y nodejs
   · CentOS/RHEL/Fedora:
       sudo yum install -y nodejs
     或 Fedora:
       sudo dnf install -y nodejs
   · 其他 Linux 或官网下载:
       https://nodejs.org/zh-cn/download/
   · 大屏和手机不需要装任何东西

3. 给启动脚本加执行权限（只需做一次）
   打开终端，进入解压目录，运行：
       chmod +x start.sh

4. 放行防火墙端口 8787（按需）
   · Ubuntu (ufw):
       sudo ufw allow 8787/tcp
   · CentOS/RHEL (firewalld):
       sudo firewall-cmd --permanent --add-port=8787/tcp
       sudo firewall-cmd --reload
   · macOS: 默认不拦截入站，通常无需配置
   · 云服务器: 还需在云控制台安全组放行 8787


───────────────────────────────────────────
二、日常使用（每次开店做这两步）
───────────────────────────────────────────

步骤 1：启动服务
  · 打开终端，进入解压目录
  · 运行:  ./start.sh
  · 终端显示服务地址，并自动打开默认浏览器到控制台
  · 终端不要关，关了服务就停
  · 记下终端里的地址，例如：
      http://192.168.1.100:8787/display.html
    （IP 以实际为准，换 WiFi 后会变）

步骤 2：打开大屏
  · 在【大屏机器】浏览器输入上面的地址
  · 页面出来后点一下屏幕解锁语音


───────────────────────────────────────────
三、扫码取号（顾客用）
───────────────────────────────────────────

1. 大屏右上角会显示一个二维码
2. 顾客用手机扫码 → 打开取号页
3. 选择机台（舞萌/中二节奏）→ 点"取号"
4. 手机显示号码（如 C001）、前方人数、预估等待时长
5. 到号时手机页面高亮提醒"到号了"，并震动

注意：
- 扫码号统一 C 前缀（C001、C002...），每机台独立计数
- 手动加号请勿用 C 开头（控制台会拦截并提示）
- 取号页地址：http://控制台IP:8787/take.html


───────────────────────────────────────────
四、控制台操作
───────────────────────────────────────────

1. 店面信息
   · 改店名/LOGO文字、标语、机台名，大屏实时变化

2. 价格表
   · 直接改项目和价格，点"+新增一行"加项目

3. 排队管理
   · 输入号码点"加入"或回车 → 加入队列
   · 点"叫下一位" → 自动叫最前面的号
   · 某号码后点"叫号" → 直接叫那个号
   · "↑"前移、"删"删除、"重叫当前"重播
   · 队列里显示每个号的预估等待时长
   · 显示"平均等待 X 分"（基于最近 10 次叫号）
   · 扫码号会标紫色"扫码"标签，和手动号区分


───────────────────────────────────────────
五、等待时长预估原理
───────────────────────────────────────────

· 每个号入队时记录时间戳
· 被叫时计算等待时长，存入历史（每机台保留最近 50 条）
· 预估 = 前方人数 × 最近 10 次平均等待时长
· 无历史数据时默认按每人 5 分钟估算
· 叫的号越多，预估越准


───────────────────────────────────────────
六、语音播报
───────────────────────────────────────────

· 语音只在大屏那台机器播报
· 首次打开大屏必须点一下屏幕解锁
· 叫号时播："请 X 号，到 XX 机台"

【推荐用 Chrome / Edge 浏览器打开大屏】
  Chromium 内核浏览器自带在线 Neural 语音，
  声音更自然可爱，接近迪拉熊效果。
  · 用 Chrome / Edge 打开大屏地址即可
  · 需要联网（在线语音从云端获取）
  · 系统会自动选最合适的语音

没声音排查：
  1. 确认大屏页面已点过解锁
  2. 推荐用 Chrome / Edge 浏览器
  3. macOS 系统语音：系统设置 → 辅助功能 → 语音 →
     添加"中文"系统语音
  4. Linux 可安装 espeak/festival 用于本地 TTS
  5. 检查音箱和音量


───────────────────────────────────────────
七、常见问题
───────────────────────────────────────────

Q: 大屏/取号页访问不到？
A: 三步排查：
   1. 确认 start.sh 终端还开着
   2. 确认防火墙已放行 8787 端口
   3. 确认两台机器连同一个 WiFi 且同网段
      （查 IP：
         macOS:   终端输入 ifconfig | grep inet
         Linux:   终端输入 ip addr 或 hostname -I
       忽略 172.x.x.x / docker 虚拟网卡）

Q: 换了 WiFi 后 IP 变了？
A: 以 start.sh 终端里显示的实际 IP 为准。
   大屏二维码会自动更新成新地址。

Q: 关机后数据丢吗？
A: 不丢。存在 state.json 里，重启自动恢复。

Q: 扫码号和手动号会冲突吗？
A: 不会。扫码号固定 C 前缀，手动加号时输入 C 开头会被拒绝。

Q: macOS 提示"无法验证开发者"？
A: 系统设置 → 隐私与安全性 → 点击"仍要打开"。
   或在终端运行: xattr -d com.apple.quarantine start.sh

Q: 后台运行（关掉终端不停服务）？
A: 使用 nohup 或 screen/tmux:
     nohup node server.js > server.log 2>&1 &
   或:
     screen -S queue
     ./start.sh
     # 按 Ctrl+A 再按 D 脱离
