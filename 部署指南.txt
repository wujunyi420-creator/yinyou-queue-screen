========================================
  音游窝社区 · Render 云部署指南
========================================

【前置准备】
1. 注册 GitHub 账号：https://github.com
2. 注册 Render 账号：https://render.com（可用 GitHub 账号登录）

【第一步：上传代码到 GitHub】
1. 在 GitHub 创建一个新仓库（Public 或 Private 均可）
   - 不要勾选 "添加 README"
   - 仓库命名如：yinyou-forum
2. 在本项目文件夹打开终端，执行：
   git init
   git add .
   git commit -m "音游窝社区论坛"
   git branch -M main
   git remote add origin https://github.com/你的用户名/yinyou-forum.git
   git push -u origin main

【第二步：在 Render 创建服务】
方式 A（推荐 · 一键 Blueprint）：
1. 登录 Render → 点 "New +" → "Blueprint"
2. 选择刚才的 GitHub 仓库
3. Render 会自动读取 render.yaml，创建 Web Service + PostgreSQL
4. 在 Environment 中填写 3 个 AI 变量：
   AI_MOD_URL   = 你的AI审核API地址
   AI_MOD_KEY   = 你的API密钥
   AI_MOD_MODEL = 你的模型名
5. 点 "Apply" 开始部署

方式 B（手动创建）：
1. 先创建 PostgreSQL：New + → PostgreSQL → Plan: Free
2. 再创建 Web Service：New + → Web Service → 连接 GitHub 仓库
   - Runtime: Node
   - Build: npm install
   - Start: node server.js
   - 环境变量加 DATABASE_URL（从 PostgreSQL 页面复制连接串）
   - 环境变量加 AI_MOD_URL / AI_MOD_KEY / AI_MOD_MODEL

【第三步：初始化数据库】
1. 部署完成后，进入 Render 的 PostgreSQL 页面
2. 点 "Shell" 或用外部工具连接数据库
3. 执行 init.sql 内容（创建 kv_store 和 images 两张表）

  CREATE TABLE IF NOT EXISTS kv_store (
    key   TEXT PRIMARY KEY,
    value JSONB NOT NULL
  );
  CREATE TABLE IF NOT EXISTS images (
    id    TEXT PRIMARY KEY,
    mime  TEXT NOT NULL DEFAULT 'image/jpeg',
    data  TEXT NOT NULL,
    created_at TIMESTAMPTZ DEFAULT NOW()
  );

【第四步：访问你的网站】
1. 在 Render 的 Web Service 页面顶部找到网址
   格式如：https://yinyou-forum.onrender.com
2. 论坛：  https://yinyou-forum.onrender.com/forum.html
3. 控制台：https://yinyou-forum.onrender.com/console.html
4. 大屏：  https://yinyou-forum.onrender.com/display.html
5. 取号：  https://yinyou-forum.onrender.com/take.html

【注意事项】
- Render 免费层会在 15 分钟无流量后休眠，首次访问需等 30-60 秒唤醒
- 免费 PostgreSQL 90 天后需手动确认续期（Render 会邮件提醒）
- AI 审核功能需要 AI_MOD 三个环境变量都填对才会启用
- 首次部署后 state 是空的，需在控制台配置店名/机台等
- 控制台默认密码 123456，请及时修改

【更新代码】
本地改代码后：
  git add .
  git commit -m "更新说明"
  git push
Render 会自动检测到 push 并重新部署。
