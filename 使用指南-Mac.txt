        排队大屏 · 使用指南 (macOS)
═══════════════════════════════════════════

【这是什么】
局域网排队叫号系统，支持：
- 控制台改 LOGO/店名/价格、管理排队、叫号
- 大屏展示排队、语音播报叫号
- 顾客手机扫码自助取号（C 前缀号码）
- 等待时长预估（基于历史叫号数据）

架构：控制台机器跑服务，大屏/手机用浏览器访问。


───────────────────────────────────────────
一、首次使用（只需做一次）
───────────────────────────────────────────

1. 解压到一个文件夹，应有以下内容：
   · start-mac.sh        启动脚本
   · server.js           服务程序
   · console.html        控制台页面
   · display.html        大屏页面
   · take.html           取号页（顾客手机用）
   · forum.html          社区论坛
   · bg.png              背景图
   · 使用指南-Mac.txt

2. 安装 Node.js（仅控制台机器需要）
   · 推荐 Homebrew:
       brew install node
     如未安装 Homebrew:
       /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
   · 或官网下载: https://nodejs.org/zh-cn/download/
   · 大屏和手机不需要装任何东西

3. 给启动脚本加执行权限（只需做一次）
   打开「终端」，进入解压目录，运行：
       chmod +x start-mac.sh
   （在 Finder 里把 .sh 文件拖到终端窗口即可自动填路径）

4. 防火墙
   · macOS 默认不拦截入站连接，通常无需配置
   · 若首次启动弹出“是否允许 node 接收网络连接”，点“允许”


───────────────────────────────────────────
二、日常使用（每次开店做这两步）
───────────────────────────────────────────

步骤 1：启动服务
  · 打开「终端」，进入解压目录
  · 运行:  ./start-mac.sh
  · 终端显示服务地址，并自动打开默认浏览器到控制台
  · 终端不要关，关了服务就停
  · 记下终端里的地址，例如：
      http://192.168.1.100:8787/display.html
    （IP 以实际为准，换 WiFi 后会变）

步骤 2：打开大屏
  · 在【大屏机器】浏览器输入上面的地址
  · 页面出来后点一下屏幕解锁语音


───────────────────────────────────────────
三、扫码取号（顾客用）
───────────────────────────────────────────

1. 大屏右上角会显示一个二维码
2. 顾客用手机扫码 → 打开取号页
3. 选择机台（舞萌/中二节奏）→ 点"取号"
4. 手机显示号码（如 C001）、前方人数、预估等待时长
5. 到号时手机页面高亮提醒"到号了"，并震动

注意：
- 扫码号统一 C 前缀（C001、C002...），每机台独立计数
- 手动加号请勿用 C 开头（控制台会拦截并提示）
- 取号页地址：http://控制台IP:8787/take.html


───────────────────────────────────────────
四、控制台操作
───────────────────────────────────────────

1. 店面信息
   · 改店名/LOGO文字、标语、机台名，大屏实时变化

2. 价格表
   · 直接改项目和价格，点"+新增一行"加项目

3. 排队管理
   · 输入号码点"加入"或回车 → 加入队列
   · 点"叫下一位" → 自动叫最前面的号
   · 某号码后点"叫号" → 直接叫那个号
   · "↑"前移、"删"删除、"重叫当前"重播
   · 队列里显示每个号的预估等待时长
   · 显示"平均等待 X 分"（基于最近 10 次叫号）
   · 扫码号会标紫色"扫码"标签，和手动号区分


───────────────────────────────────────────
五、语音播报（macOS 专属说明）
───────────────────────────────────────────

· 语音只在大屏那台机器播报
· 首次打开大屏必须点一下屏幕解锁
· 叫号时播："请 X 号，到 XX 机台"

【强烈推荐用 Edge / Chrome 浏览器打开大屏】
  Chromium 内核浏览器自带在线 Neural 语音
  （如微软 Xiaoyi、Google 中文女声），声音自然可爱。
  · 用 Edge / Chrome 打开大屏地址即可，无需安装
  · 需要联网（在线语音从云端获取）
  · 系统会自动选最合适的语音
  · macOS 上 Edge 下载: https://www.microsoft.com/edge

【Safari 兼容方案】
  Safari 调用 macOS 系统语音包，需提前下载中文语音：
  · 系统设置 → 辅助功能 → 语音 → 系统语音 → "管理..."
  · 添加 "Ting-Ting"（中文 - 中国大陆，女声）
  · 可选 "Li-mu"（中文 - 中国大陆，男声）
  · 下载完成后重启 Safari

【系统 TTS（say 命令）说明】
  macOS 自带 say 命令可用于脚本调用，但本项目未直接使用。
  如需测试系统语音：
      say -v Ting-Ting "请 001 号到舞萌机台"

没声音排查：
  1. 确认大屏页面已点过解锁
  2. 推荐改用 Edge / Chrome 浏览器（在线 Neural 语音最好）
  3. 用 Safari 时确认已下载 Ting-Ting 中文语音包
  4. 检查系统音量、浏览器是否被静音


───────────────────────────────────────────
六、常见问题
───────────────────────────────────────────

Q: 大屏/取号页访问不到？
A: 三步排查：
   1. 确认 start-mac.sh 终端还开着
   2. 确认两台机器连同一个 WiFi 且同网段
      （查 IP：终端输入 ifconfig | grep inet，
       忽略 172.x.x.x / docker 虚拟网卡）
   3. 若用的是云服务器/路由器隔离网络，需放行 8787 端口

Q: 换了 WiFi 后 IP 变了？
A: 以 start-mac.sh 终端里显示的实际 IP 为准。
   大屏二维码会自动更新成新地址。

Q: 关机后数据丢吗？
A: 不丢。存在 state.json 里，重启自动恢复。

Q: 扫码号和手动号会冲突吗？
A: 不会。扫码号固定 C 前缀，手动加号时输入 C 开头会被拒绝。

Q: 提示"无法验证开发者"/"无法打开 start-mac.sh"？
A: macOS 安全机制拦截，二选一：
   · 系统设置 → 隐私与安全性 → 点击"仍要打开"
   · 或终端运行: xattr -d com.apple.quarantine start-mac.sh

Q: 后台运行（关掉终端不停服务）？
A: 使用 nohup 或 screen/tmux:
     nohup node server.js > server.log 2>&1 &
   或:
     screen -S queue
     ./start-mac.sh
     # 按 Ctrl+A 再按 D 脱离
