        排队大屏 · 使用指南 (Linux)
═══════════════════════════════════════════

【这是什么】
局域网排队叫号系统，支持：
- 控制台改 LOGO/店名/价格、管理排队、叫号
- 大屏展示排队、语音播报叫号
- 顾客手机扫码自助取号（C 前缀号码）
- 等待时长预估（基于历史叫号数据）

架构：控制台机器跑服务，大屏/手机用浏览器访问。


───────────────────────────────────────────
一、首次使用（只需做一次）
───────────────────────────────────────────

1. 解压到一个文件夹，应有以下内容：
   · start-linux.sh       启动脚本（含 TTS 检测）
   · server.js            服务程序
   · console.html         控制台页面
   · display.html         大屏页面
   · take.html            取号页（顾客手机用）
   · forum.html           社区论坛
   · bg.png               背景图
   · 使用指南-Linux.txt

2. 安装 Node.js（仅控制台机器需要）
   · Ubuntu/Debian:
       sudo apt update && sudo apt install -y nodejs
   · CentOS/RHEL:
       sudo yum install -y nodejs
   · Fedora:
       sudo dnf install -y nodejs
   · Arch Linux:
       sudo pacman -S nodejs
   · openSUSE:
       sudo zypper install -y nodejs
   · 或官网下载: https://nodejs.org/zh-cn/download/
   · 大屏和手机不需要装任何东西

3. 给启动脚本加执行权限（只需做一次）
   打开终端，进入解压目录，运行：
       chmod +x start-linux.sh

4. 放行防火墙端口 8787
   · Ubuntu (ufw):
       sudo ufw allow 8787/tcp
   · CentOS/RHEL/Fedora (firewalld):
       sudo firewall-cmd --permanent --add-port=8787/tcp
       sudo firewall-cmd --reload
   · 云服务器: 还需在云控制台安全组放行 8787


───────────────────────────────────────────
二、日常使用（每次开店做这两步）
───────────────────────────────────────────

步骤 1：启动服务
  · 打开终端，进入解压目录
  · 运行:  ./start-linux.sh
  · 终端显示服务地址，并自动打开默认浏览器到控制台
  · 终端不要关，关了服务就停
  · 记下终端里的地址，例如：
      http://192.168.1.100:8787/display.html
    （IP 以实际为准，换 WiFi 后会变）

步骤 2：打开大屏
  · 在【大屏机器】浏览器输入上面的地址
  · 页面出来后点一下屏幕解锁语音


───────────────────────────────────────────
三、扫码取号（顾客用）
───────────────────────────────────────────

1. 大屏右上角会显示一个二维码
2. 顾客用手机扫码 → 打开取号页
3. 选择机台（舞萌/中二节奏）→ 点"取号"
4. 手机显示号码（如 C001）、前方人数、预估等待时长
5. 到号时手机页面高亮提醒"到号了"，并震动

注意：
- 扫码号统一 C 前缀（C001、C002...），每机台独立计数
- 手动加号请勿用 C 开头（控制台会拦截并提示）
- 取号页地址：http://控制台IP:8787/take.html


───────────────────────────────────────────
四、控制台操作
───────────────────────────────────────────

1. 店面信息
   · 改店名/LOGO文字、标语、机台名，大屏实时变化

2. 价格表
   · 直接改项目和价格，点"+新增一行"加项目

3. 排队管理
   · 输入号码点"加入"或回车 → 加入队列
   · 点"叫下一位" → 自动叫最前面的号
   · 某号码后点"叫号" → 直接叫那个号
   · "↑"前移、"删"删除、"重叫当前"重播
   · 队列里显示每个号的预估等待时长
   · 显示"平均等待 X 分"（基于最近 10 次叫号）
   · 扫码号会标紫色"扫码"标签，和手动号区分


───────────────────────────────────────────
五、等待时长预估原理
───────────────────────────────────────────

· 每个号入队时记录时间戳
· 被叫时计算等待时长，存入历史（每机台保留最近 50 条）
· 预估 = 前方人数 × 最近 10 次平均等待时长
· 无历史数据时默认按每人 5 分钟估算
· 叫的号越多，预估越准


═══════════════════════════════════════════
六、语音播报 (Linux 专属 · 重点章节)
═══════════════════════════════════════════

【为什么 Linux 语音需要单独配置？】
· 语音只在大屏那台机器播报
· 首次打开大屏必须点一下屏幕解锁
· 叫号时播："请 X 号，到 XX 机台"

与 Windows/Mac 不同，Linux 上的浏览器（Chrome/Edge/Firefox）
普遍不带在线 Neural 语音，Web Speech API 会回退到系统 TTS 引擎。
=> 不装系统语音包，大屏叫号很可能完全没声音！


【方案 A：espeak-ng —— 轻量兜底，推荐先装】

Ubuntu/Debian:
    sudo apt install -y espeak-ng espeak-ng-data
CentOS/RHEL/Fedora:
    sudo dnf install -y espeak-ng
Arch Linux:
    sudo pacman -S espeak-ng
openSUSE:
    sudo zypper install -y espeak-ng

测试中文语音：
    espeak-ng -v zh "请 001 号到舞萌机台"

特点：
· 安装简单，几 MB 大小
· 所有发行版都有包
· 缺点：声音偏机械生硬，不像迪拉熊


【方案 B：Piper —— 神经网络语音，质量好】

Piper 是高质量本地神经网络 TTS，适合追求音质的店铺。

1) 下载 Piper 二进制:
   https://github.com/rhasspy/piper/releases
   选择 piper_linux_x86_64.tar.gz

2) 解压并下载中文模型:
   # 假设解压到 ~/piper
   cd ~/piper
   # 下载中文女声模型（约 60MB）
   wget https://huggingface.co/rhasspy/piper-voices/resolve/v1.0.0/zh/zh_CN/huayan/medium/zh_CN-huayan-medium.onnx
   wget https://huggingface.co/rhasspy/piper-voices/resolve/v1.0.0/zh/zh_CN/huayan/medium/zh_CN-huayan-medium.onnx.json

3) 测试:
   ./piper --model zh_CN-huayan-medium.onnx --output_file /tmp/test.wav < <<"请 001 号到舞萌机台"
   aplay /tmp/test.wav

4) 让浏览器调用 Piper:
   需通过 speech-dispatcher 桥接，配置较复杂。
   详见: https://github.com/rhasspy/piper


【方案 C：speech-dispatcher —— 统一调度】

若系统已装多个 TTS 引擎，推荐用 speech-dispatcher 统一管理:

    sudo apt install -y speech-dispatcher
    spd-conf                    # 交互配置
    spd-say -l zh "测试中文"

浏览器（Firefox）有时会自动识别 speech-dispatcher。


【方案 D：最简单 —— 用别的设备当大屏机】

如果不折腾 Linux TTS，推荐：
· 把 Linux 机器只用来跑 server.js（服务端）
· 大屏用 Windows 平板 / Mac / Android 平板浏览器打开
  http://Linux机器IP:8787/display.html
· 这样大屏语音由 Windows/Mac/Android 系统负责，质量天然更好


【start-linux.sh 的 TTS 检测功能】

启动脚本内置 TTS 检测，三种用法：

  # 普通启动（仅提示是否缺 TTS）
  ./start-linux.sh

  # 首次启动时自动引导安装 espeak-ng
  INSTALL_TTS=1 ./start-linux.sh

  # 已装好或不在意语音，跳过检测
  SKIP_TTS_CHECK=1 ./start-linux.sh


没声音排查清单：
  1. 确认大屏页面已点过解锁
  2. 确认已安装 espeak-ng 且有中文语音数据
     espeak-ng --voices=zh     # 应输出至少一行
  3. 浏览器静音？地址栏 chrome://settings/content/sound 检查
  4. 系统音量 / 音频输出设备是否正常
     speaker-test -t sine -f 440    # 测试是否能出声
  5. 实在搞不定 → 改用方案 D（其他设备当大屏）


───────────────────────────────────────────
七、常见问题
───────────────────────────────────────────

Q: 大屏/取号页访问不到？
A: 三步排查：
   1. 确认 start-linux.sh 终端还开着
   2. 确认防火墙已放行 8787 端口
      sudo ufw status          # Ubuntu
      sudo firewall-cmd --list-ports   # CentOS
   3. 确认两台机器连同一个 WiFi 且同网段
      （查 IP: hostname -I 或 ip addr
       忽略 172.x.x.x / docker 虚拟网卡）

Q: 换了 WiFi 后 IP 变了？
A: 以 start-linux.sh 终端里显示的实际 IP 为准。
   大屏二维码会自动更新成新地址。

Q: 关机后数据丢吗？
A: 不丢。存在 state.json 里，重启自动恢复。

Q: 扫码号和手动号会冲突吗？
A: 不会。扫码号固定 C 前缀，手动加号时输入 C 开头会被拒绝。

Q: 大屏没声音？
A: 见第六章「没声音排查清单」。Linux 必须装 TTS 才能出声。

Q: 后台运行（关掉终端不停服务）？
A: 使用 nohup 或 screen/tmux:
     nohup node server.js > server.log 2>&1 &
   或:
     screen -S queue
     ./start-linux.sh
     # 按 Ctrl+A 再按 D 脱离

Q: 开机自启？
A: 用 systemd 写 service 文件，例如:
   sudo tee /etc/systemd/system/queue-screen.service <<'EOF'
   [Unit]
   Description=Queue Screen Service
   After=network.target

   [Service]
   Type=simple
   User=你的用户名
   WorkingDirectory=/path/to/queue-screen
   ExecStart=/usr/bin/node server.js
   Restart=on-failure

   [Install]
   WantedBy=multi-user.target
   EOF
   sudo systemctl enable --now queue-screen.service
